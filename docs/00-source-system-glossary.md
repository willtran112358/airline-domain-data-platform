# Source systems — Singapore Airlines context

| Acronym | Full name | Role |
|---------|-----------|------|
| **PSS** | Passenger Service System | Bookings, tickets, segments (Amadeus) |
| **DCS** | Departure Control System | Check-in, boarding, bags (hub **SIN**) |
| **OCC** | Operations Control Center | Delays, diversions, recovery |
| **RMS** | Revenue Management System | Bid prices, inventory, yield |
| **PSP** | Payment Service Provider | Card / wallet auth (PCI-scoped) |
| **PNR** | Passenger Name Record | Booking locator |
| **EMD** | Electronic Miscellaneous Document | Ancillary document in PSS |
| **OTP** | On-Time Performance | Actual vs scheduled |
| **KrisFlyer** | Loyalty program | Tier, miles, PPS Club |
| **SSOT** | Single Source of Truth | `golden_passenger_id` / passenger 360 |
