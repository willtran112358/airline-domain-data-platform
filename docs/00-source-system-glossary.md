# Source system glossary (English full names)

All portfolio docs use these **full English names** on first mention; acronyms in parentheses are optional shorthand.

| Acronym | Full name (English) | Role in airline data platform |
|---------|---------------------|------------------------------|
| **PSS** | **Passenger Service System** | System of record for bookings, passengers, tickets, segments (e.g. Navitaire, Amadeus, Sabre) |
| **CRS** | **Computer Reservation System** | Distribution / reservation layer; often paired with PSS in vendor stacks |
| **DCS** | **Departure Control System** | Airport check-in, seat assignment, boarding, bag tags |
| **OCC** | **Operations Control Center** | Network disruption management, delays, diversions, crew/aircraft recovery |
| **RMS** | **Revenue Management System** | Forecasting, bid prices, inventory controls, yield optimization |
| **CRM** | **Customer Relationship Management** | Sales, service cases, campaign audiences |
| **PSP** | **Payment Service Provider** | Card / wallet auth and capture (PCI-scoped) |
| **EMD** | **Electronic Miscellaneous Document** | Ancillary document in PSS (bags, seats, fees) |
| **PNR** | **Passenger Name Record** | Booking locator tying passengers and segments |
| **OTP** | **On-Time Performance** | Operational KPI — actual vs scheduled arrival/departure |
| **ACARS** | **Aircraft Communications Addressing and Reporting System** | Telex-style aircraft–ground operational messages |
| **ODS** | **Operational Data Store** | Departmental staging / mart (legacy pattern) |
| **SSOT** | **Single Source of Truth** | Governed conformed entity (e.g. passenger 360) |
